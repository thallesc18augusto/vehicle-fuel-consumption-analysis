# vehicle-fuel-consumption-analysis

## Project Overview

This project explores vehicle fuel consumption across different automotive brands and models, investigating how engine size, fuel type, vehicle class, and other characteristics influence fuel efficiency.

## Objectives

- Compare fuel consumption across different vehicle brands and models.
- Investigate the relationship between engine size and fuel consumption.
- Analyze fuel efficiency across different fuel types.
- Identify patterns and trends through data analysis.
- Develop machine learning models to predict fuel consumption and classify vehicle efficiency.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Models

**Regression:**
- Linear Regression
- Random Forest Regression

**Classification:**
- Logistic Regression
- Random Forest Classification

**Optimization:**
- RandomizedSearchCV
